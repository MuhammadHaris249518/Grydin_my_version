# Asset library

- `source/` holds editable or higher-quality source artwork, organized by format or subject. These files are project masters and are not automatically published.
- `reference/` holds screenshots and copy snapshots used as design/content references. These files are not used by the running website.
- Website-served assets live in `../public/assets/` and are addressed by URL from the site, for example `/assets/brand/logo-black.png`.

Keep the source/reference materials here and publish only assets needed by the website from `public/assets/`.
